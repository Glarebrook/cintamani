# Cintamani

NAS에서 서빙하는 브라우저 웹게임.

## 실행 방법

NAS 웹 서버(예: Synology Web Station, NGINX) 루트에 이 폴더를 배치한 뒤 `index.html`을 서빙하면 됩니다.  
별도 빌드 과정 없이 정적 파일만으로 동작합니다.

## 폴더 구조

```
/
├── index.html              진입점
├── css/
│   └── style.css           전역 스타일
├── js/
│   ├── constants.js        게임 상수 (CELL_SIZE, GRID, 타이밍 등)
│   ├── input.js            키보드 입력 처리
│   ├── snake.js            뱀 클래스 (이동, 성장, 충돌)
│   ├── items.js            아이템 관리 (먹이 스폰/충돌)
│   ├── enemies.js          적 관리 (향후 확장)
│   ├── renderer.js         캔버스 렌더링
│   ├── game.js             게임 루프 및 틱 로직
│   └── main.js             초기화 진입점
└── assets/
    ├── images/             스프라이트, 배경 등
    └── audio/              효과음, BGM
```
