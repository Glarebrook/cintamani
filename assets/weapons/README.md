# 무기 아이콘 이미지 템플릿

독침/비늘파동을 처음 잠금 해제하는 순간 뜨는 튜토리얼 팝업 상단에 작게 들어가는
아이콘입니다. 이 폴더에 아래 2개 파일을 이 이름 그대로 넣으면 자동으로 적용됩니다.
파일이 없는 항목은 팝업에서 그 무기를 상징하는 색(독침: 노란색, 비늘파동: 흰색)의
원으로 자동 대체되므로, 하나씩 채워가며 확인할 수 있습니다.

## 필요한 파일

| 파일명 | 대상 |
|---|---|
| `venom.png` | 독침(뱀 머리에서 나가는 투사체) |
| `scaleWave.png` | 비늘파동(충전형 광역 공격) |

## 규격

- 정사각형 PNG, 배경 투명
- 64×64px 권장 (실제 화면에는 훨씬 작게 축소되어 표시됨 - 도트/블록 느낌으로 그리면 축소됐을 때 더 선명함)
