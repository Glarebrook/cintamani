# 적 아이콘 이미지 템플릿

하단 상태창의 2열(적1~5 킬 스택)과, **실제 필드에 스폰되는 적 본체**(managers/enemyManager.js)
둘 다에 쓰이는 이미지입니다 - 같은 파일 하나로 두 군데 다 적용됩니다. 이 폴더에 아래 5개
파일을 이 이름 그대로 넣으면 자동으로 적용됩니다. 파일이 없는 항목은(둘 다) 그 적의 기존
색깔로 된 네모/원 도형으로 자동 대체되므로, 하나씩 채워가며 확인할 수 있습니다. 필드에서는
이미지 위에 남은 HP 숫자가 계속 겹쳐서 표시됩니다(기존과 동일).

## 필요한 파일

| 파일명 | 대상 |
|---|---|
| `enemy1.png` | 1번적 (기본형, 빨강) |
| `enemy2.png` | 2번적 (고정 포획존형, 파랑) |
| `enemy2_b.png` (선택) | 2번적 애니메이션 2번째 프레임 - 있으면 `enemy2.png`와 0.3초 간격으로 번갈아 그려져 움직이는 것처럼 보임(없으면 지금처럼 정지 이미지) |
| `enemy3.png` | 3번적 (추격형, 빨강) |
| `enemy4.png` | 4번적 (고정 포탑형, 파랑) |
| `enemy5.png` | 5번적 (추적 사격형, 초록) |

## 규격

- 정사각형 PNG, 배경 투명
- 64×64px 권장 (실제 화면에는 훨씬 작게 축소되어 표시됨 - 도트/블록 느낌으로 그리면 축소됐을 때 더 선명함)
