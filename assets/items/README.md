# 아이템 아이콘 이미지 템플릿

필드에 놓인 아이템을 색깔 사각형 대신 그려주는 이미지입니다. `assets/enemies/README.md`와
같은 패턴 - 파일이 없으면 자동으로 기존 색깔 네모로 대체됩니다.

## 필요한 파일

| 파일명 | 대상 |
|---|---|
| `item1_a.png` | 기본 먹이(초록) 애니메이션 1번째 프레임 |
| `item1_b.png` | 기본 먹이(초록) 애니메이션 2번째 프레임 - `item1_a.png`와 0.3초 간격으로 번갈아 그려짐 |

## 규격

- 정사각형 PNG, 배경 투명
- 64×64px 권장 (실제 화면에는 훨씬 작게 축소되어 표시됨)
