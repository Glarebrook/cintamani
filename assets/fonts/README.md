# 게임 전용 폰트 파일

이 폴더에는 두 가지 폰트를 넣을 수 있습니다. 파일이 없으면 지금까지처럼 기본 폰트로 그대로
보입니다 - 다른 에셋들과 같은 "없으면 폴백" 방식입니다.

## 1. `game.*` — 게임 타이틀/장식용 폰트

타이틀 화면 "CINTAMANI" 로고, 게임오버 문구, 점수 팝업, 적 HP 숫자 등 장식적인 느낌이 필요한
곳에 쓰입니다. 파일이 없으면 monospace로 폴백합니다.

| 파일명 | 형식 |
|---|---|
| `game.woff2` | WOFF2 (권장 - 용량 가장 작음) |
| `game.woff` | WOFF |
| `game.ttf` | TrueType |
| `game.otf` | OpenType |

## 2. `ui_light.*` / `ui_bold.*` — 상태창/패치노트용 가독성 폰트

좌측 상태창(속도·길이·킬스택·CINTAMANI 개수 등 숫자 위주 정보)과 타이틀 화면의 패치노트
패널처럼, 정보를 빠르게 읽어야 하는 곳에 쓰입니다. `game.*`와 별도의 폰트를 쓸 수 있도록
분리해뒀습니다. 파일이 없으면 sans-serif로 폴백합니다(장식용 폰트와 달리 애초에 "더 읽기
편한 폰트"가 목적이라 폴백도 그 방향에 맞춤).

일반/굵게 두 굵기를 각각 다른 폰트 파일로 씁니다(하나의 파일을 브라우저가 인위적으로
두껍게 그리는 "가짜 볼드"가 아니라, 실제로 디자인된 두 개의 파일을 그대로 씀) - 코드에서
굵게(`bold`) 요청하면 자동으로 `ui_bold.*`가, 일반 굵기 요청이면 `ui_light.*`가 쓰입니다.

| 파일명 | 형식 | 용도 |
|---|---|---|
| `ui_light.woff2` / `.woff` / `.ttf` / `.otf` | (형식은 갖고 계신 파일에 맞는 확장자 하나만) | 일반 굵기 |
| `ui_bold.woff2` / `.woff` / `.ttf` / `.otf` | (형식은 갖고 계신 파일에 맞는 확장자 하나만) | 굵게(bold) |

## 넣는 방법

갖고 계신 폰트 파일의 확장자에 맞춰 파일명만 `game.<확장자>` / `ui_light.<확장자>` /
`ui_bold.<확장자>`로 바꿔서 이 폴더에 넣으시면 됩니다(각각 여러 형식을 동시에 넣어도
상관없고, 그중 브라우저가 지원하는 걸 알아서 골라 씁니다). 세 파일은 완전히 독립적이라,
일부만 먼저 넣어도 됩니다 - 예를 들어 `ui_bold.*` 없이 `ui_light.*`만 넣으면, 굵게 표시되는
곳은 일단 sans-serif 폴백으로 보이다가 나중에 `ui_bold.*`를 추가하면 그때부터 적용됩니다.

## 참고

- css/style.css의 `@font-face` 규칙(`CintamaniFont`/`UIFont`, `UIFont`는 굵기별로 2개)이 이
  폴더를 가리키고 있습니다.
- 폰트 로딩은 비동기라, 새로고침 직후 아주 잠깐 폴백 폰트로 보였다가 로딩이 끝나면 바로 이
  폰트로 바뀔 수 있습니다(이미지 아이콘들과 동일한 타이밍 특성).
