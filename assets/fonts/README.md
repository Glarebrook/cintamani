# 게임 전용 폰트 파일

화면 통계바/리더보드 같은 DOM 글씨와, 캔버스에 그리는 모든 글씨(상태창/점수/팝업/HP 등)에
전부 적용되는 폰트입니다. 이 폴더에 아래 파일명 중 하나로(갖고 있는 파일 형식에 맞는 확장자
하나만) 넣으면 자동으로 적용됩니다. 파일이 없으면 지금까지처럼 기본 monospace 폰트로 그대로
보입니다 - 다른 에셋들과 같은 "없으면 폴백" 방식입니다.

## 필요한 파일 (하나만 있으면 됨)

| 파일명 | 형식 |
|---|---|
| `game.woff2` | WOFF2 (권장 - 용량 가장 작음) |
| `game.woff` | WOFF |
| `game.ttf` | TrueType |
| `game.otf` | OpenType |

갖고 계신 폰트 파일의 확장자에 맞춰 파일명만 `game.<확장자>`로 바꿔서 이 폴더에 넣으시면
됩니다(여러 개를 동시에 넣어도 상관없고, 그중 브라우저가 지원하는 걸 알아서 골라 씁니다).

## 참고

- css/style.css의 `@font-face` 규칙이 이 폴더를 가리키고 있습니다.
- 폰트 로딩은 비동기라, 새로고침 직후 아주 잠깐 기본 monospace로 보였다가 로딩이 끝나면
  바로 이 폰트로 바뀔 수 있습니다(이미지 아이콘들과 동일한 타이밍 특성).
