# 이무기 스프라이트 시트 가이드

- 파일: `snake_spritesheet.png`
- 규격: **4행 × 4열, 각 칸 64×64px** (전체 256×256px)
- 좌표 읽는 법: `행`은 위→아래(1~4), `열`은 왼→오른(1~4)
- 렌더 시 **`image-rendering: pixelated`** 필수 (확대해도 도트 유지)

방향 표기: → 오른쪽 / ← 왼쪽 / ↑ 위 / ↓ 아래

---

## 1행 — 몸통 (Body)

| 위치 | 용도 |
|---|---|
| 1행 1열 | → 이동 시 몸통 (가로) |
| 1행 2열 | ← 이동 시 몸통 (가로) — 1행1열과 동일 이미지 |
| 1행 3열 | ↑ 이동 시 몸통 (세로) |
| 1행 4열 | ↓ 이동 시 몸통 (세로) — 1행3열과 동일 이미지 |

몸통은 좌우대칭 원통이라 **가로 1종·세로 1종**이면 충분하지만, 방향으로 바로 골라 쓰도록 4칸에 배치. 먹이를 먹으면 머리와 꼬리 사이에 이 몸통 칸을 계속 이어 붙이면 됨.

## 2행 — 머리 (Head)

| 위치 | 용도 |
|---|---|
| 2행 1열 | → 이동 시 머리 (옆모습, 오른쪽 바라봄) |
| 2행 2열 | ← 이동 시 머리 (옆모습, 왼쪽 바라봄) |
| 2행 3열 | ↑ 이동 시 머리 (**위에서 내려다본 정수리 뷰**, 주둥이 위쪽) |
| 2행 4열 | ↓ 이동 시 머리 (**정수리 뷰**, 주둥이 아래쪽) |

좌/우는 옆얼굴, 위/아래는 머리통을 내려다본 모습.

## 3행 — 꼬리 (Tail)

| 위치 | 용도 |
|---|---|
| 3행 1열 | → 이동 시 꼬리 (끝이 왼쪽으로) |
| 3행 2열 | ← 이동 시 꼬리 (끝이 오른쪽으로) |
| 3행 3열 | ↑ 이동 시 꼬리 (끝이 아래로) |
| 3행 4열 | ↓ 이동 시 꼬리 (끝이 위로) |

머리·꼬리 모두 **진행 방향**으로 열을 고르면 됨 (1열=→, 2열=←, 3열=↑, 4열=↓).

## 4행 — 코너 (Corner, 꺾이는 칸)

꺾이는 칸은 직선 몸통을 회전시키면 잘려 보이므로 **전용 곡선 조각**을 씀. 각 조각은 **연결하는 두 변**으로 구분:

| 위치 | 잇는 두 변 | 이웃 위치 | 이런 회전에 사용 |
|---|---|---|---|
| 4행 1열 | 서 + 남 (W+S) | 왼쪽 · 아래 | ↑ 가다 ← 꺾기 / → 가다 ↓ 꺾기 |
| 4행 2열 | 북 + 서 (N+W) | 위 · 왼쪽 | ↓ 가다 ← 꺾기 / → 가다 ↑ 꺾기 |
| 4행 3열 | 북 + 동 (N+E) | 위 · 오른쪽 | ↓ 가다 → 꺾기 / ← 가다 ↑ 꺾기 |
| 4행 4열 | 남 + 동 (S+E) | 아래 · 오른쪽 | ↑ 가다 → 꺾기 / ← 가다 ↓ 꺾기 |

---

## 렌더 로직 요약

각 칸마다 앞칸(머리쪽)·뒤칸(꼬리쪽) 두 이웃이 어느 방향에 있는지 본다.

1. **머리 칸**: 진행 방향으로 2행에서 선택 (→2행1열, ←2행2열, ↑2행3열, ↓2행4열)
2. **꼬리 칸**: 진행 방향으로 3행에서 선택 (열 규칙 동일)
3. **가운데 몸통 칸**:
   - 두 이웃이 **반대 방향**(동-서 또는 남-북) → 직선 몸통 (1행: 가로면 1열, 세로면 3열)
   - 두 이웃이 **직각**(예: 위-오른쪽) → 4행에서 그 두 변을 잇는 코너 선택

```
// 두 이웃 방향의 집합으로 조각 결정
const s = new Set([dirToPrev, dirToNext]);   // 'N'|'S'|'E'|'W'
if (s.has('E') && s.has('W')) use(row1col1);         // 가로 직선
else if (s.has('N') && s.has('S')) use(row1col3);    // 세로 직선
else {
  const key = [...s].sort().join('');   // 'SW','NW','EN','ES'
  use({ SW:'r4c1', NW:'r4c2', EN:'r4c3', ES:'r4c4' }[key]);
}
```

몸통이 좌우대칭이라 어느 방향으로 회전·꺾여도 안쪽·바깥쪽 색이 동일하게 이어진다.
