# 뱀 스프라이트 이미지 템플릿

이 폴더에 아래 8개 파일을 이 이름 그대로 넣으면 뱀 머리/몸통이 색깔 네모 대신 이미지로 표시됩니다.
파일이 아직 없는 방향은 자동으로 기존 색깔 네모로 대체되므로, 하나씩 채워가며 확인할 수 있습니다.

## 필요한 파일

| 파일명 | 용도 |
|---|---|
| `head_up.png` | 머리가 위쪽으로 이동 중일 때 |
| `head_down.png` | 머리가 아래쪽으로 이동 중일 때 |
| `head_left.png` | 머리가 왼쪽으로 이동 중일 때 |
| `head_right.png` | 머리가 오른쪽으로 이동 중일 때 |
| `body_up.png` | 몸통 칸이 위쪽으로 이어질 때 |
| `body_down.png` | 몸통 칸이 아래쪽으로 이어질 때 |
| `body_left.png` | 몸통 칸이 왼쪽으로 이어질 때 |
| `body_right.png` | 몸통 칸이 오른쪽으로 이어질 때 |

꼬리는 `body_*` 이미지를 그대로 재사용합니다. 나중에 꼬리 전용 그림이 필요해지면 별도로 추가할 수 있습니다.

## 규격

- 정사각형 PNG, 배경 투명
- 32×32px 또는 64×64px 권장 (실제 화면에는 16×16px로 축소되어 표시됨 — `CELL_SIZE` 기준)
- 부드러운 그라데이션보다 도트/블록 느낌으로 그리면 축소됐을 때 더 선명하게 보입니다 (`image-rendering: pixelated` 적용됨)
