# 뱀 스프라이트시트

- 파일명: `snake_spritesheet.png` (필수 — 없으면 지금까지처럼 색깔 사각형 + 척추선으로 자동 폴백)
- 규격: **4행 × 4열, 칸당 64×64px** (전체 256×256px), 투명 배경 권장
- 칸 배치/방향 규칙은 `snake_spritesheet_guide.md`(원본 가이드 문서)를 그대로 따른다 - 요약:
  - 1행(몸통 직선): 1~2열=가로(동일 이미지), 3~4열=세로(동일 이미지)
  - 2행(머리): 진행 방향 기준 1열=→, 2열=←, 3열=↑, 4열=↓
  - 3행(꼬리): **머리와 같은 열 배치**(1열=→, 2열=←, 3열=↑, 4열=↓) - 다만 여기서 "진행 방향"은
    "꼬리 칸에서 바로 앞 칸(머리쪽 이웃)으로 가는 방향"을 뜻한다(뱀 전체가 그 순간 향하던
    방향과 같음, "꼬리 끝이 뾰족하게 가리키는 방향"이 아님) - `js/render/snakeSprites.js`/
    `js/render/layers.js`의 `resolveSpriteRect` 주석 참고. 처음 구현 시 이 방향을 반대로 계산해
    남/북이 뒤집히는 버그가 있었고, 실제 이미지+가이드 문서 대조로 수정함.
  - 4행(코너): 1열=남서(SW), 2열=북서(NW), 3열=북동(NE), 4열=남동(SE)
- `js/render/snakeSprites.js`가 로딩하고, `js/render/layers.js`의 `snakeLayer`가 이 파일이
  있으면 스프라이트로, 없으면 기존 방식(색깔 사각형 + 척추선)으로 그린다.
- 아이템 섭취 시 머리→꼬리로 흘러가는 반짝임 효과는 각 칸에 그려진 스프라이트 모양 그대로만
  틴트된다(사각형 전체가 아니라) - `layers.js`의 `tintSprite`(오프스크린 캔버스 + source-atop)
  참고.

`snake_curve_demo.png`, `snake_spritesheet_guide.png`/`.md`는 참고용 파일로, 게임 코드가 직접
로딩하지는 않는다.
