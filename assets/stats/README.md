# 상태창 스탯 아이콘 이미지 템플릿

하단 상태창의 1열(속도/길이/독침 데미지/비늘파동 데미지)에서, 각 수치 위에 작게 들어가는
아이콘입니다. 이 폴더에 아래 파일을 이 이름 그대로 넣으면 자동으로 적용됩니다. 파일이
없는 항목은 그 스탯을 상징하는 색의 원으로 자동 대체되므로, 하나씩 채워가며 확인할 수
있습니다. 독침/비늘파동 아이콘은 이 폴더가 아니라 `assets/weapons/venom.png`,
`assets/weapons/scaleWave.png`를 그대로 재사용합니다(무기 튜토리얼 팝업과 같은 이미지).

## 필요한 파일

| 파일명 | 대상 |
|---|---|
| `speed.png` | 속도 |
| `length.png` | 길이 |

## 규격

- 정사각형 PNG, 배경 투명
- 64×64px 권장 (실제 화면에는 훨씬 작게 축소되어 표시됨 - 도트/블록 느낌으로 그리면 축소됐을 때 더 선명함)
