# 여의주 아이콘 이미지 템플릿

하단 상태창의 3열(여의주 4종, 2×2 배치)에 쓰이는 아이콘입니다. 여의주는 아직 게임 안에
실제로 존재하는 개념이 아니라서 개수는 항상 0으로 표시되지만, 아이콘 자리는 미리
잡아뒀습니다. 이 폴더에 아래 4개 파일을 이 이름 그대로 넣으면 자동으로 적용됩니다.
파일이 없는 항목은 해당 색 원 도형으로 자동 대체됩니다.

## 필요한 파일

| 파일명 | 대상 |
|---|---|
| `red.png` | 적 여의주 |
| `blue.png` | 청 여의주 |
| `green.png` | 녹 여의주 |
| `yellow.png` | 황 여의주 |

## 규격

- 정사각형 PNG, 배경 투명
- 64×64px 권장 (실제 화면에는 훨씬 작게 축소되어 표시됨 - 도트/블록 느낌으로 그리면 축소됐을 때 더 선명함)
