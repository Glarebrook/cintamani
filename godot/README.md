# 이무기 (가제) — Godot 버전

"뱀이 용이 되어 가는 게임"을 **Godot 4** 게임 엔진으로 새로 만드는 폴더입니다.
기존 웹 버전(저장소 맨 위의 `index.html`, `js/` 등)은 시험용 프로토타입으로 그대로 두었고,
앞으로의 개발은 이 `godot/` 폴더에서 합니다.

지금 들어 있는 것은 **뼈대 + 연못 스테이지 한 판**입니다. 그림은 전부 네모 도형(임시)이고, 소리 파일은 아직 없습니다. (없어도 오류 없이 동작)

### 연못 스테이지에서 할 수 있는 것

- 뱀은 초당 2칸씩 움직이고, 먹이를 먹으면 길어집니다. 벽이나 자기 몸, 장애물·적에 머리를 부딪히면 게임 오버.
- **바위**: 고정. 체력 5, 독침·화염으로 부숨. 맞을수록 금이 감. 5개 부술 때마다 보라 먹이.
- **가재**: 고정, 집게만 까딱거림. 독침이 안 통하고 **똬리틀기**(몸으로 둘러 가두기)로만 없앰. 없애면 15% 확률로 주황 먹이.
- **똬리틀기**: 대상 주변 3칸(옅은 네모) 안에서 몸으로 한 바퀴 둘러 가두면 대상이 사라지고, 그 직후 한 번은 자기 몸을 통과해 빠져나올 수 있음.
- **잉어**: 상하좌우로 돌아다님(뱀 처음 속도). 5칸 안에 들어오면 3배 빨라져 쫓아옴. 체력 10, 닿으면 죽음. 죽은 자리에 노란 먹이.
- **진주조개**: 고정, 똬리틀기로만 없앰. 머리가 가로·세로 줄에 들어오는 순간 진주 발사(독침 2배 속도). 머리에 맞으면 죽음, 몸에 맞으면 2칸 줄어듦. 없애면 초록 60% / 노랑+주황 붙어서 30% / 갈색 10%.
- **장어**: 갈색 먹이를 15초 넘게 두면 장어로 변함. 뱀과 같은 속도로 쫓아오고, 머리가 줄에 들어오면 3연발. 몸에 한 발 맞을 때마다 갈색 먹이만큼 줄고 느려짐. 체력 20, 보상 없음.
- **먹이 5종** (처음 먹을 때 설명 팝업): 초록(+1), 노랑(+1, 빨라짐), 갈색(-2, 느려짐, 15초 지나면 장어), 보라(+3), 주황(독침 피해 +1만)
- **독침**: 길이가 +5 되면 배움. 스페이스바로 발사.
- **비늘파동**: 잉어 5마리를 잡으면 배움. 스페이스바를 1초 누르고 떼면 몸 주변 적에게 큰 피해 + 잠깐 무적.
- **불의 여의주**: 잉어 10마리마다 1개. A 키로 앞쪽 직선(폭 3칸)에 화염.
- 스킬/여의주는 처음 얻을 때 설명 팝업이 뜨고, 이후에는 왼쪽 상태창에만 표시됩니다.
- **보스 대왕메기**: 불의 여의주를 10개 모으고 길이가 +50이 되면 개구리 비명과 함께 등장. 쫓아오면서 네 방향으로 물줄기를 쏩니다.
- 대왕메기를 쓰러뜨리면 "으악!" → 개구리가 고마워하며 뭍으로 올라오라고 제안 → 자동 저장 → "뭍"(RPG 스테이지, 아직 빈 화면)으로 이동.
- ESC 일시정지 메뉴(저장/불러오기/설정), 게임오버 화면, 설정(창 크기, 전체 화면, 음량)

## 1. Godot 설치하고 실행하기 (처음 한 번)

1. https://godotengine.org/download 에 들어가서 **Godot Engine 4.x (Standard 버전)** 을 받습니다.
   - "4.3" 이상이면 됩니다. ".NET" 이라고 적힌 버전 말고 그냥 **Standard** 를 받으세요.
   - 설치 과정이 없습니다. 받은 zip 파일을 풀면 나오는 `Godot_v4...exe`(맥은 `Godot.app`)를 바로 실행하면 됩니다.
2. Godot 를 켜면 "프로젝트 매니저" 창이 뜹니다. **가져오기(Import)** 를 누르고,
   이 저장소의 `godot/project.godot` 파일을 선택한 뒤 **가져오기 & 편집** 을 누릅니다.
   - 영어로 나오면: 오른쪽 위 Settings → Language 에서 한국어로 바꿀 수 있습니다.
   - 처음 열 때 4.3보다 새 버전이면 "프로젝트를 변환할까요?" 같은 창이 뜰 수 있습니다. 확인을 누르면 됩니다.
3. 에디터가 열리면 오른쪽 위의 **▶ (재생 버튼, 단축키 F5)** 를 누르면 게임이 실행됩니다.

### 조작법

| 키 | 하는 일 |
|---|---|
| 방향키 | 뱀이 나아갈 방향 |
| Space | 독침 발사 (비늘파동을 배운 뒤에는 1초 누르고 떼면 비늘파동) |
| A | 불의 여의주 사용 (화염) |
| Enter | 대화·설명 팝업 넘기기, 메뉴 선택 |
| ESC | 일시정지 메뉴 |

> 설명 팝업은 Enter 로만 닫힙니다. 방향키나 스페이스를 누르다가 모르고 넘겨 버리지 않게 하려고요.

> 키는 "물리적 키 위치"로 잡혀 있어서, 한글 입력 상태에서도 그대로 동작합니다.
> 키를 바꾸려면 에디터 메뉴 **프로젝트 → 프로젝트 설정 → 입력 맵** 에서 바꿉니다.

## 2. 용어 몇 가지

| 용어 | 뜻 |
|---|---|
| 씬(Scene) | 화면 하나, 또는 화면에 들어가는 부품 하나. `.tscn` 파일. (타이틀 화면, 대화창 등) |
| 스크립트 | 씬이 어떻게 움직일지 적은 코드. `.gd` 파일 (GDScript, 파이썬과 비슷한 문법) |
| 오토로드(Autoload) | 게임 내내 항상 켜져 있는 관리자. 어느 씬에서든 이름으로 부를 수 있음 (`GameState`, `SaveManager` 등) |
| 틱(Tick) | 뱀이 한 칸 움직이는 주기. 연못은 처음에 0.16초 |
| `res://` | 이 `godot/` 폴더를 뜻하는 Godot 식 경로 |
| `user://` | 세이브/설정 파일이 저장되는 개인 폴더 (Windows: `%APPDATA%\Godot\app_userdata\이무기 (가제)`) |

## 3. 폴더 구조

```
godot/
├── project.godot        프로젝트 설정 (해상도 640x360, 도트용 픽셀 설정, 키 설정, 오토로드 목록)
├── icon.svg
│
├── data/                ★ 게임 "내용" — 코드를 몰라도 고칠 수 있는 곳
│   ├── stages.json        스테이지 목록 (판 크기, 속도, 적 등장, 스킬 습득 조건, 보스 조건, 다음 스테이지)
│   ├── obstacles.json     장애물 (바위, 가재) — 체력, 똬리틀기, 부수면 나오는 먹이
│   ├── enemies.json       적 (잉어, 장어, 진주조개, 대왕메기) — 체력, 움직임, 공격, 떨어뜨리는 먹이
│   ├── items.json         먹이 5종, 여의주(불/물/흙/나무)
│   ├── skills.json        스킬 (독침, 비늘파동, 불의 여의주 화염) — 피해량, 속도, 범위
│   ├── tutorials.json     처음 얻을 때 뜨는 설명 팝업 글
│   ├── dialogues.json     대사 (보스 등장, 클리어)
│   ├── characters.json    플레이할 이무기 (지금은 강철이 1종, 색만 사용)
│   ├── texts.json         화면에 쓰는 짧은 문구 (죽은 이유 등)
│   └── audio.json         소리 이름 → 소리 파일 경로
│
├── autoload/            항상 켜져 있는 관리자들
│   ├── data_db.gd         [Data] data/ 의 JSON 을 전부 읽어 둠
│   ├── game_state.gd      [GameState] 진행 상황 전체를 한 덩어리로 들고 있음 (= 저장되는 내용)
│   ├── save_manager.gd    [SaveManager] GameState 를 파일로 저장/불러오기
│   ├── settings.gd        [Settings] 창 크기, 전체 화면, 소리 크기
│   ├── audio_manager.gd   [AudioManager] 배경음/효과음 재생
│   └── scene_manager.gd   [SceneManager] 화면 이동 (타이틀 ↔ 스테이지 ↔ 게임오버)
│
├── scenes/
│   ├── title/             타이틀 화면
│   ├── stage_snake/       스네이크 스테이지 (연못, 나중에 개울·호수·강·바다도 여기서)
│   │   ├── snake_stage.*    화면: 입력 받기, 틱 돌리기, 그리기, 클리어/게임오버 처리
│   │   └── snake_board.gd   규칙: 이동, 충돌, 먹이, 적, 투사체, 스킬, 보스 조건 (화면과 분리돼 있음)
│   ├── stage_rpg/         RPG 스테이지 자리 (뭍·산기슭·평원) — 아직 "준비 중" 화면만
│   ├── game_over/         게임오버 화면
│   └── ui/                여러 화면이 같이 쓰는 부품
│       ├── status_panel.*   왼쪽 상태창
│       ├── dialogue_box.*   대화창 (타자기식 텍스트)
│       ├── info_popup.*     처음 얻은 스킬/먹이 설명 팝업
│       ├── pause_menu.*     ESC 일시정지 메뉴
│       ├── settings_menu.*  설정 창
│       └── ui_kit.gd        버튼/패널 만드는 도우미
│
└── assets/              그림·소리·글꼴 (지금은 비어 있음)
    ├── sprites/
    ├── audio/bgm/  audio/sfx/
    └── fonts/
```

### 게임 흐름

```
타이틀 ─ 새로 시작 ─▶ 연못(스네이크) ─ 여의주 10개 + 길이 +50 ─▶ 대왕메기 등장 ─ 처치 ─▶ 개구리 대사 ─▶ 자동 저장 ─▶ 뭍(RPG, 준비 중)
   ▲                     │ 죽음
   │                     ▼
   └──── 타이틀로 ──── 게임오버 ── 다시 하기 ──▶ 같은 스테이지 처음부터
```

### 저장은 어떻게 되나요?

- 진행 상황은 전부 `GameState.data` 한 덩어리에 들어 있습니다:
  현재 스테이지, 열린 스테이지, 여의주 개수, 선악 점수(karma), 이야기 진행 표시(flags), 스테이지별 최고 길이.
- **저장 = 이 덩어리를 `user://save_1.json` 에 통째로 쓰기**, 불러오기 = 다시 읽어 오기.
- 지금은 "어느 스테이지까지 왔는지"를 저장하고, 불러오면 그 스테이지를 **처음부터** 시작합니다.
  (스네이크 판 한가운데 상태까지 저장하는 건 필요해지면 나중에)
- 새로 저장할 게 생기면 `autoload/game_state.gd` 의 `new_game()` 기본값에 한 줄 추가하면 끝입니다.
  예전 세이브 파일에는 그 항목이 없어도 기본값으로 채워지므로 깨지지 않습니다.

## 4. 새 기능은 어디에 붙이나요?

| 하고 싶은 것 | 고칠 곳 |
|---|---|
| 난이도 숫자 바꾸기 | 아래 "숫자 바꾸는 곳" 표 참고. 전부 JSON 파일만 고치면 됨 |
| 대사 바꾸기·추가 | `data/dialogues.json` (스테이지 시작 대사를 넣고 싶으면 `stages.json` 에 `"intro_dialogue": "대사id"` 추가) |
| 설명 팝업 글 바꾸기 | `data/tutorials.json` |
| 새 적·장애물 추가 | ① `enemies.json`(또는 `obstacles.json`)에 항목 추가 ② 스테이지의 `enemy_spawn.table`(또는 `initial_obstacles`)에 넣기. 움직임(`wander`/`chase`), 공격(`line`/`cross`), 독침 무효(`damage_immune`), 똬리틀기(`coil`)는 이미 있는 것 중에 고르면 코드 수정 없음. 새 행동이 필요하면 `snake_board.gd` 에 추가. 모양은 `snake_stage.gd` 의 `_draw_creature` |
| 새 먹이 종류 | `data/items.json` 에 추가(`grow`, `shrink`, `speed_ms`, `venom_damage` 조합) + 어떤 적이 떨어뜨릴지 `drops` 에 넣기 |
| 스킬 배우는 조건 바꾸기 | `stages.json` 의 `skill_unlocks` |
| 새 스네이크 스테이지 (개울, 호수 …) | `data/stages.json` 에 `"type": "snake"` 로 추가하고, 앞 스테이지의 `next_stage` 를 새 id 로 |
| RPG 스테이지 만들기 | `scenes/stage_rpg/` (지금은 자리만 있음). 대화창·일시정지 메뉴는 이미 들어 있음 |
| 여의주 스킬 | 여의주 종류는 `items.json` 에 있음. 사용 효과는 `snake_stage.gd` 의 `action_main`(Space) 자리나 새 키(ASDF)에 연결 |
| 그림 넣기 | `assets/sprites/` 에 PNG 넣고, `snake_stage.gd` 의 "그리기" 부분을 스프라이트로 교체 |
| 소리 넣기 | `assets/audio/` 에 파일 넣고 `data/audio.json` 경로만 맞추면 자동 재생 (배경음은 Godot 에서 파일 선택 → 가져오기 탭 → Loop 체크) |
| 한글 도트 글꼴 | `assets/fonts/` 에 글꼴(예: 갈무리 Galmuri, 무료) 넣고 프로젝트 설정 → GUI → 테마 → 커스텀 글꼴 |
| 캐릭터 선택 (강철이/율무기/훼룡) | `data/characters.json` 에 추가. 선택 화면은 나중에 타이틀 뒤에 붙임 |
| 새 저장 항목 (선택지 결과 등) | `autoload/game_state.gd` 의 `new_game()` |

### JSON 을 고칠 때 주의

- 마지막 항목 뒤에는 쉼표(`,`)를 붙이지 않습니다.
- 글자는 반드시 큰따옴표(`"`)로 감쌉니다.
- 잘못 고치면 Godot 아래쪽 "출력" 창에 `JSON 형식이 잘못되었습니다` 라는 빨간 글씨가 뜹니다.

## 5. 숫자 바꾸는 곳 (난이도 조절)

아직 정하지 않은 난이도 숫자는 전부 **임시값**입니다. 아래 위치만 고치면 바로 반영됩니다.

| 바꾸고 싶은 것 | 파일 | 항목 | 지금 값 |
|---|---|---|---|
| 맵 크기 (가로, 세로 칸 수) | `data/stages.json` → `pond` | `grid_size` | `[28, 20]` (임시) |
| 시작 길이 | 〃 | `start_length` | 3 |
| 시작 속도 (한 칸에 걸리는 시간 ms, 작을수록 빠름) | 〃 | `tick_ms` | 500 (= 초당 2칸) |
| 가장 빠른/느린 속도 | 〃 | `min_tick_ms` / `max_tick_ms` | 150 / 800 |
| 노란/갈색 먹이 한 번에 바뀌는 속도 | `data/items.json` | `speed_ms` | 노랑 -50, 갈색 +50 |
| 먹이가 생기는 간격·최대 개수 | `data/stages.json` | `food_spawns` | 초록 3~6초마다 (최대 4개), 갈색 25~40초마다 (최대 1개) |
| 갈색 먹이가 장어로 변하는 시간 | `data/items.json` → `speed_down` | `transform.after_ms` | 15000 (15초) |
| 처음 놓이는 바위·가재 수 | `data/stages.json` | `initial_obstacles` | 바위 8, 가재 2 |
| 적·장애물이 새로 나오는 간격 | 〃 | `enemy_spawn.interval_ms` | 4~7초 |
| 종류별 등장 비율·최대 수·조건 | 〃 | `enemy_spawn.table` | 잉어 6(최대 4), 바위 3(최대 8), 가재 1(최대 2), 진주조개 2(최대 2, 길이 +5부터) |
| 똬리틀기 직후 몸 통과가 허용되는 시간 | 〃 | `coil_pass_through_ticks` | 20칸 이동 동안 (한 번 통과하면 바로 끝) |
| 독침 배우는 조건 | 〃 | `skill_unlocks.venom` | 길이 +5 |
| 비늘파동 배우는 조건 | 〃 | `skill_unlocks.scale_wave` | 잉어 5마리 |
| 불의 여의주 얻는 조건 | 〃 | `cintamani_rewards` | 잉어 10마리마다 1개 |
| 보스 등장 조건 | 〃 | `boss.requires` | 불의 여의주 10개(쓴 것 포함, 모은 총 개수) + 길이 +50 |
| 잉어 체력·속도·추격 | `data/enemies.json` → `carp` | `hp`, `move` | 체력 10, 평소 뱀 처음 속도, 5칸 안이면 3배 빨라져 추격 |
| 장어 체력·연발 | 〃 → `eel` | `hp`, `shoot.burst` | 체력 20, 3연발 |
| 진주조개·장어 투사체 속도 | 〃 | `shoot.speed_vs_venom` | 독침의 2배 |
| 진주에 몸이 맞았을 때 줄어드는 칸 | 〃 → `pearl_clam` | `shoot.body_shrink` | 2 (장어는 `body_as_item` = 갈색 먹이와 같은 효과) |
| 똬리틀기 범위 | `data/obstacles.json`·`enemies.json` | `coil.range` | 3칸 |
| 바위 체력, 보라 먹이 스택 | `data/obstacles.json` → `rock` | `hp`, `kill_bonus.every` | 5, 5개마다 |
| 부쉈을 때 나오는 먹이와 확률 | 각 생물의 `drops` | | 진주조개 초록 60 : 노랑+주황 30 : 갈색 10, 가재 주황 15 : 없음 85, 잉어 노랑 100 |
| 스킬 피해량·속도·범위 | `data/skills.json` | `damage`, `speed_cells_per_sec` 등 | 독침 1 (초당 10칸), 비늘파동 5, 화염 30 |

`drops` 의 `weight` 는 "비율"입니다. `items` 에 먹이를 두 개 넣으면 둘이 바로 붙어서 나오고, `place` 가 `"here"` 면 부서진 자리, `"random"` 이면 맵 아무 곳에 나옵니다.

## 6. 화면/도트 설정

- 게임 화면 기본 크기는 **640×360** 이고, 창은 이걸 정수배(1·2·3배)로 키워서 보여 줍니다. 도트가 번지지 않게 하기 위해서입니다.
- 그림 확대 시 흐릿해지지 않도록 **픽셀 필터를 껐습니다** (`project.godot` 의 `default_texture_filter=0`, 즉 Nearest).
- 연못 판은 30×20 칸, 한 칸 16픽셀. 왼쪽 144픽셀은 상태창입니다.
